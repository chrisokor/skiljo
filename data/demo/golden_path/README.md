# Golden Path Demo Dataset

This directory freezes the small interview/demo dataset used by the readiness docs.

Files:

- `policy.txt` — compact refund policy with automatic approval, human-review, VIP, and fraud-review clauses.
- `tickets.csv` — 12 historical tickets in the API import format.
- `expected_summary.json` — expected report-level metrics for the committed sample report artifact.

The sample report is generated by `scripts/generate_sample_report.py` and committed at:

- `docs/demo-artifacts/sample-diagnostic-report.html`

This bundle is for explanation and demo rehearsal. Real extraction output can vary by model and prompt version, so any real-provider demo should record the model, date, prompt version, and resulting metrics separately.
